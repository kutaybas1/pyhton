# GTA 5 PRO MAX ULTRA

Tek dosyalık, harici bağımlılık gerektirmeyen tarayıcı oyunu. GTA tarzı açık şehir; araç sürme, trafik, polis/aranma sistemi, teslimat, banka soygunu, yarış, market yükseltmeleri ve gizemli monster truck içerir.

## Oynat

- `index.html` dosyasını tarayıcıda aç.
- GitHub Pages için kök dizindeki `index.html` yeterlidir.
- `mini-sehir-gta.html`, aynı oyunun kaynak kopyasıdır.

## Evren Birleşmesi

İlk iki ölümde hastanede yeniden doğarsın. **Üçüncü ölümde** mor portallar açılır ve şehir, altı evrenin birleştiği boss arenasına dönüşür.

Boss sırası:

1. Sonic
2. Creeper / Minecraft
3. Thanos / Avengers
4. Arthur Morgan / Red Dead Redemption 2
5. Sans / Undertale
6. Hulk

Arenada sol tık ile evren ateşi, Space ile dash kullanılır. Arenada ölürsen bossun canı korunur. Altı bossun tamamı yenildiğinde şehre dönülür ve **$2.500** ödül verilir.

## GitHub Pages

1. GitHub'da public bir repo oluştur.
2. `index.html` ve `README.md` dosyalarını repoya yükle.
3. Repo → **Settings → Pages** → **Deploy from a branch** → `main` / `root` seç.
4. Birkaç dakika sonra `https://KULLANICI_ADIN.github.io/REPO_ADI/` adresinde açılır.
